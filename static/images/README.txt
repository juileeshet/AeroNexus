Optional: use your own photo as the hero / login background
===========================================================
Save a landscape photo here named  hero-bg.jpg  (also accepted: .jpeg, .webp, .png).
AeroNexus detects it automatically on the next page load and uses it behind the
home page banner, the page banners and the login screens, under a navy tint so
text stays readable. Delete the file to go back to the built-in animated sky.

Free photo sources (always read the license shown on each photo):
  - https://unsplash.com/s/photos/airplane-sky
  - https://www.pexels.com/search/airplane%20window/
  - https://pixabay.com/images/search/airplane/
Tip: pick a wide image around 1920px across, under 500 KB, with open sky.
